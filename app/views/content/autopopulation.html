Auto-population opportunities

Fields that could be pre-populated across the three export document journeys: Catch Certificate (CC), Processing Statement (PS), and Non-Manipulation Document / Storage Document (NMD/SD).

Users complete these journeys in order: CC first, then PS, then NMD/SD. Data entered in an earlier journey could be carried forward to reduce re-entry and errors.

# Field pre-populated Source journey and field Target journey and field Benefit Priority
1 Catch certificate reference CC — the certificate's own unique reference number, generated on submission PS — "Catch certificate" reference field Users currently copy the CC reference manually into PS. Pre-filling removes a transcription step and reduces the risk of entering the wrong reference number. High
2 Species weight on catch certificate CC — "Export weight (kg)" PS — "Species weight on catch certificate" The CC export weight is exactly what PS asks for. Users currently look this up from their CC and re-enter it. Pre-filling reduces errors and effort. High
3 Entry document reference PS — the processing statement's own unique reference number, generated on submission NMD/SD — "Entry document" reference field The PS reference is what NMD/SD asks for as the entry document. Pre-filling removes a manual look-up and copy step. High
4 Weight on entry document PS — "Export weight after processing" NMD/SD — "Weight on entry document" The weight leaving PS is the same weight arriving at NMD/SD. Pre-filling this directly links the two documents and reduces the chance of inconsistencies. High
5 Species CC — "FAO code or species name" PS — "Species" field The same species travels from CC into PS. Pre-filling avoids re-entry and ensures consistency between the two documents. Medium
6 Commodity code CC — "Commodity code" PS — "Commodity code" / NMD/SD — commodity code The commodity code may change between journeys if the fish is processed into a different product, so pre-filling should be editable. Still reduces effort when the code does not change. Medium
7 Exporter details CC — company name and address PS — exporter name and address / NMD/SD — exporter name and address The same business is the exporter across all three documents. Pre-filling avoids re-entering the same company details three times. Medium
8 Destination country CC — destination country (transport section) PS — destination country / NMD/SD — destination country If the fish is going to the same destination throughout the chain, this field repeats across all three journeys. Should be editable in case the destination changes. Low
